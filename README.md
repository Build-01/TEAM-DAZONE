# SabiWork by Team DaZone

## The Problem We Solve

Africa's informal economy employs over 80% of the workforce, yet most workers lack formal records, credit access, pensions, insurance, and financial services. Because existing systems depend on traditional banking data, millions remain excluded, vulnerable to fraud, non-payment, and persistent poverty.

## Our Solution

Our solution is an AI-powered platform that creates digital economic identities for informal workers. It onboards them, matches them to jobs, automates pension savings, and builds verified trust credentials through an Economic Identity Score based on work activity, transactions, pension contributions, community trust, and repayment behavior. This enables banks to offer credit safely, while workers gain financial visibility, secure payments, and long-term economic opportunities. We provide trust credentials, not lending.

## Squad APIs Used

| API | Purpose |
|-----|---------|
| **Escrow transactions** | Secure gig payments |
| **Instant worker payouts** | Immediate net payment |
| **Pension contribution transfers** | Auto-pension deductions |
| **Payment webhooks** | Trigger trust updates & monitoring |
| **Transaction reconciliation** | Match gig records with pension/payout logs |

## Pillars Addressed

| Pillar | Description |
|--------|-------------|
| **AI** | Skill extraction from photos, job matching, fraud detection, behavioral trust scoring, pension consistency scoring, labor forecasting |
| **Use of Data** | Alternative data (gig completion, escrow history, savings, community endorsements) replaces traditional credit history |
| **Financial Innovation** | Automated pension inclusion for informal workers + trust-based credit credentials without lending risk; invisible labor becomes measurable economic participation |
| **Squad API** | Escrow, instant payouts, automated pension transfers, webhook-triggered monitoring — Squad is our financial backbone |
